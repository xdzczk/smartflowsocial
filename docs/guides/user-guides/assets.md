## Overview

SmartFlowSocial's asset management allows you to:

- **Upload media files** (images, videos)
- **Create text assets** (reusable text content)
- **Organize assets** with titles and tags
- **Bulk manage** multiple assets
- **Reuse assets** in posts
- **Delete unused assets**

### Asset Types

**Media Assets:**

- Images (JPG, PNG, GIF, WebP)
- Videos (MP4, WebM, MOV)
- Automatically resized/optimized

**Text Assets:**

- Reusable text content
- Templates for posts
- Captions and descriptions

## Uploading Assets

### Single Media Upload

**How to upload:**

1. Go to **Assets** page
2. Click **"Upload"** tab
3. Select **"Add Single Media"**
4. Enter title (optional)
5. Add tags (optional)
6. Choose file
7. Click **"Upload"**

**Supported formats:**

- Images: JPG, PNG, GIF, WebP
- Videos: MP4, WebM, MOV

**File processing:**

- Images automatically resized
- Optimized for web
- Original quality preserved when possible

### Bulk Media Upload

**How to upload:**

1. Go to **Assets** page
2. Click **"Upload"** tab
3. Select **"Bulk Upload Media"**
4. Enter title prefix (optional)
5. Add tags (optional)
6. Select multiple files
7. Click **"Upload All"**

**Bulk upload features:**

- Upload multiple files at once
- Title prefix applied to all
- Same tags for all files
- Progress tracking

### Text Asset Creation

**How to create:**

1. Go to **Assets** page
2. Click **"Upload"** tab
3. Select **"Add Text Asset"**
4. Enter title (optional)
5. Enter text content
6. Add tags (optional)
7. Click **"Create"**

**Use cases:**

- Reusable captions
- Post templates
- Standard messages
- Common text snippets

## Managing Assets

### Viewing Assets

**Asset list displays:**

- Thumbnail (for media)
- Title
- Type (IMAGE, VIDEO, TEXT)
- Tags
- Upload date
- File URL

**Filtering:**

- Search by title or tags
- Filter by type
- Sort by date

### Editing Assets

**Editable fields:**

- Title
- Tags
- Content (text assets only)

**How to edit:**

1. Find asset in list
2. Click **"Edit"**
3. Modify fields
4. Click **"Save"**

### Deleting Assets

**Single delete:**

1. Find asset in list
2. Click **"Delete"**
3. Confirm deletion

**Bulk delete:**

1. Select multiple assets
2. Click **"Delete Selected"**
3. Confirm deletion

**Note:** Deleted assets cannot be recovered

## Using Assets in Posts

### Adding Media to Posts

**From asset library:**

1. Create new post
2. Click **"Add Media"**
3. Select from assets
4. Media added to post

**Direct upload:**

1. Create new post
2. Click **"Upload"**
3. Upload new file
4. File added to post and assets

### Using Text Assets

**In posts:**

1. Create new post
2. Click **"Insert Text Asset"**
3. Select text asset
4. Content inserted
5. Edit as needed

**As templates:**

1. Select text asset
2. Use as starting point
3. Customize for specific post
4. Save as new post

## Bulk Operations

### Bulk Selection

**How to select:**

1. Check individual assets
2. Or click **"Select All"**
3. Selected assets highlighted

**Selection features:**

- Select individual assets
- Select all assets
- Clear selection

### Bulk Posting

**How to bulk post:**

1. Select multiple assets
2. Click **"Bulk Post"**
3. Redirected to bulk post page
4. Assets pre-filled
5. Configure scheduling
6. Post or schedule

**Bulk post features:**

- All selected assets included
- Configure queue for all
- Set schedule interval
- Post as batch

### Bulk Delete

**How to bulk delete:**

1. Select multiple assets
2. Click **"Delete Selected"**
3. Confirm deletion
4. All selected assets deleted

**Use cases:**

- Clean up unused assets
- Remove old content
- Free up storage

## Asset Organization

### Titles

**Purpose:**

- Identify assets quickly
- Organize by content
- Search functionality

**Best practices:**

- Use descriptive titles
- Include date or category
- Keep titles concise

**Examples:**

- `Bitcoin Meme 2026-01`
- `Product Launch Image`
- `Weekly Update Template`

### Tags

**Purpose:**

- Categorize assets
- Filter and search
- Group related content

**Best practices:**

- Use consistent tags
- Multiple tags per asset
- Create tag system

**Examples:**

- `meme bitcoin lightning`
- `product launch announcement`
- `template weekly-update`

### Organization Strategy

**By content type:**

- Memes
- Announcements
- Templates
- Product images

**By date:**

- 2026-01
- 2026-02
- Weekly batches

**By campaign:**

- Campaign name
- Product launch
- Event promotion

### Upload Strategy

1. **Organize before upload:**

   - Use consistent naming
   - Add titles immediately
   - Tag appropriately

2. **Optimize files:**

   - Compress large images
   - Use appropriate formats
   - Check file sizes

3. **Bulk upload:**
   - Group related files
   - Use title prefixes
   - Apply common tags

### Asset Management

1. **Regular cleanup:**

2. **Tag consistently:**

3. **Update regularly:**
   - Refresh templates

## Troubleshooting

### Upload Fails

**Possible causes:**

- File too large
- Unsupported format
- Network issues
- Storage quota exceeded

**Solutions:**

- Check file size
- Verify format
- Try again
- Check storage settings

### Assets Not Showing

**Possible causes:**

- Filter too restrictive
- Search query incorrect
- Assets deleted
- Cache issues

**Solutions:**

- Clear filters
- Check search query
- Refresh page
- Clear browser cache

### Bulk Operations Not Working

**Possible causes:**

- No assets selected
- Too many assets
- Network issues

**Solutions:**

- Select assets first
- Try smaller batches
- Check connection
- Try again
