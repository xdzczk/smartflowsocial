# SmartFlowSocial — Marketing imagery from product screenshots

Practical guidance for social creatives built from **real in-app captures**. Pair with `smartflow-brand-creative-brief.md` and `smartflow-brand-tokens.json`.

## How visuals should feel

- **Serious creator tooling:** Calm confidence — **queues, schedules, calendars, proof flows** — not generic “growth hacker” energy.
- **Material honesty:** Prefer screenshots that still look like **the actual product** after mild grading. Avoid artificial bloom or color overlays that fake mood.
- **Warm light / cool dark:** If you grade, push **slightly warm whites** in light mode comps and **neutral charcoal** (not blue-black) in dark mode comps — matches the app.

## Purple accent dosage

- **Default:** Purple appears on **primary buttons, active nav, toggles, focus, selection chips** — typically **<10% of pixels** in a full dashboard shot.
- **Marketing overlay:** Use purple for **one CTA**, **one headline word**, or a **thin accent rule** — not full-bleed violet backgrounds.
- **Gradient headlines** (optional): **Slate → purple** vertical gradient on one hero line is on-brand; **rainbow / teal-purple-pink** is not.

## Framing screenshots

- **Aspect:** 4:5, 1:1, and 16:9 all work; **leave ~6–8% safe margin** on edges for platform UI and captions.
- **Crop:** Include **enough chrome** (sidebar + header) to prove it’s real software **unless** the story is a single modal — then crop tight with rounded corners matching **~14–16px** radius.
- **Depth:** A faint **outer shadow** on the screenshot block mimics in-app card elevation — OK; avoid **thick device bezels** unless brand-approved templates exist.

## Text overlays

- **Type:** Kanit or close geometric sans; **weights 600–700** for headlines, **400–500** for subheads.
- **Contrast:** Place text on **solid scrims** or **clean margins** — not directly over dense tables without backing.
- **Copy length:** **Headline ≤ 6 words**; **subhead ≤ 12 words**. Let the UI show complexity.

## Callouts & annotations

- Match **in-product** restraint: **small pills**, **hairline borders**, **neutral fills** from token secondary backgrounds.
- **Arrows:** Single-color, muted — optional subtle purple dot at arrowhead only if emphasis is needed.
- **Avoid:** Explosion badges, **3D stickers**, starbursts, **“NEW”** ribbons unless they exist in-product.

## Escaping generic SaaS poster aesthetics

**Signals of generic:**

- Full-screen **mesh gradients** unrelated to product colors.
- **Glass panels** with heavy blur over unrelated stock imagery.
- **Five accent colors** in one composition.
- **Isometric illustrations** replacing real UI for product claims.

**SmartFlow-aligned alternatives:**

- **Screenshot-forward** layouts with **one** narrative hook (e.g. “Next post queued”).
- **Neutral poster margin** + **single elevated card** cluster.
- **Data-forward crops:** calendar grid, Flow strip, queue badges — **proof of workflow**.

## Composition patterns that fit

1. **Hero + inset UI:** Headline left or top; **one rounded screenshot** with authentic shadow.
2. **Before/after timeline:** Minimal — **scheduled → published** using real calendar/Flow visuals.
3. **Feature spotlight:** Zoomed panel with **2–3 callouts** tied to real controls.
4. **Dark-mode prestige:** Full-bleed charcoal background; **one lit panel** (the product surface) as focal point — purple **only** on CTAs inside the shot.

## Good vs bad styling directions

| Direction | Reads as… |
|-----------|-----------|
| **Good:** Warm off-white canvas, white card cluster, purple only on buttons and one headline accent | Credible operator product |
| **Good:** Dark UI screenshot on charcoal field, generous padding | Premium tooling |
| **Bad:** Purple-to-pink gradient hero with tiny unrelated UI thumbnail | Startup cliché |
| **Bad:** Neon outlines on screenshot + excessive glow | Gaming/crypto meme |
| **Bad:** All-neutral grayscale screenshot + random coral CTA | Brand fracture |

## Canonical screens for reference-based generation

Use **logged-in, realistic data** (queues, scheduled items, events) so captures look like live operations. See **Recommended reference screens** in `smartflow-brand-creative-brief.md` for route-level recommendations.
