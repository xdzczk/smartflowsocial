# Hosted Quick Start

**Estimated time:** 5 minutes  
**Difficulty:** Beginner  
**Last updated:** 2026-01-03

This guide is for **hosted customers** using SmartFlowSocial at [smartflow.social](https://smartflow.social).

---

## Prerequisites

- A NIP-07 compatible Nostr extension (Alby / nos2x / Amber)

---

## Step 1: Log in

1. Open [smartflow.social](https://smartflow.social)
2. Click **Log in with Nostr**
3. Approve the login request in your Nostr extension

---

## Step 2: Create your first post

1. Open the posting flow in the dashboard
2. Write your content and add media (optional)
3. Choose **Post now** or **Schedule**

If you schedule, make sure your scheduled event is signed when prompted.

---

## Step 3: Use queues (optional, recommended for consistent cadence)

Queues let you define a posting schedule once and then drop posts into that schedule.

- Create a queue type (name + rules)
- Add posts to the queue
- Let the worker publish automatically at the next slot

## Troubleshooting

If login prompts don’t appear:

- Check your Nostr extension is installed and enabled
- Reload the page
- Try a different supported extension

See [Common issues](../troubleshooting/common-issues.md) for more.
