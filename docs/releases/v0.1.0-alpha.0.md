# SmartFlowSocial 0.1.0-alpha.0

14 November 2026. These are the notes for tag `v0.1.0-alpha.0`.

`package.json` version is `0.1.0-alpha.0`. The package is `"private": true`. Do not publish it to
npm. The application is distributed as source.

## What this alpha is

A Nostr scheduler you can run yourself. You sign with a NIP-07 extension or a NIP-46 remote signer.
The server stores the signed event and publishes it later. The same repository is what the hosted
service is built from. A live deploy can lag this commit until the operator updates it.

## Minimum runtime

- Node.js 20 or newer. `.nvmrc` and the Railpack image use Node 22.
- pnpm 10.27.0 (`packageManager` in `package.json`).
- PostgreSQL 14+ and Redis 6+.
- An HTTP publisher. The production component is
  [smartflowsocial-publisher](https://github.com/xdzczk/smartflowsocial-publisher).
  `pnpm publisher:local` is a local signature check for development only.
- S3-compatible storage only if you upload media.

Blastr, Blossom, the cache worker, and NostrMash are optional and live in their own repositories.

## Install

Follow [the self-host smoke](../getting-started/self-host-smoke.md). The short form after
dependencies are installed:

```bash
pnpm docker
pnpm exec prisma generate
pnpm exec prisma db push
pnpm publisher:local   # second terminal, or run the real publisher
pnpm smoke:publish
pnpm dev             # already includes the worker
```

Production after `pnpm build`: `pnpm start` for the web process and `pnpm start:worker` for the
worker. Those are two processes. Do not run `pnpm start:worker` next to `pnpm dev`.

## Known limitations

- React Router 6.30.6 still has two moderate advisories. The patched release is 7.18.0, which is a
  Remix migration, not a patch. See [dependency advisories](../security/dependency-advisories.md).
- There is no in-app account export and no single control that erases an account. Deleting a post
  removes the app row. Relays keep events they already accepted.
- Referral payouts are off when `REFERRAL_PAYOUTS_ENABLED=false`. An existing hosted environment
  that does not set the variable keeps payout execution and does not need the manual-payout secret
  merely to boot. The manual route still returns 401 without that secret.
- The local publisher does not broadcast to relays.
- k6 in CI measures a fixture unless a staging URL is configured. That is not an application
  benchmark. Staging credentials are not in the repository.
- Historical Git commits still contain a personal iCloud address. See
  [commit metadata](../privacy/commit-metadata.md). Do not rewrite history without an explicit
  decision.

## Publishing the release

Publish from `main` after this commit is on that branch. Do not force-push.

1. Confirm `main` contains the commit you intend to ship.
2. `git tag -a v0.1.0-alpha.0 -m "SmartFlowSocial 0.1.0-alpha.0"`
3. `git push origin v0.1.0-alpha.0`
4. Create the GitHub Release from that tag. Use this file as the body. Mark it as a pre-release.
5. Do not `npm publish`.

The hosted service is a separate deploy. Tagging the repository does not deploy production.
