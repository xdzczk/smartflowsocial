# Adding Images to Posts

**Estimated time:** 15 minutes  
**Difficulty:** Beginner  
**Last updated:** 2026-01-02

Learn how to add images to your posts to make them more engaging and visually appealing.

---

## Prerequisites

- ✅ Account created and logged in
- ✅ Completed [Creating Your First Post](./creating-your-first-post.md)
- ✅ Images ready to upload (JPG, PNG, WebP, or GIF)

---

## Step 1: Start a New Post

1. **Click "New Post"** in navigation
2. **Post creation page** opens
3. **Select "Media Post"** tab (if not already selected)

---

## Step 2: Upload an Image

**Option 1: Click to Upload**

1. **Click "Choose File"** or drag area
2. **Select image** from your computer
3. **Image uploads** automatically
4. **Preview appears** below

**Option 2: Drag and Drop**

1. **Open file explorer**
2. **Drag image** into upload area
3. **Drop image** when area highlights
4. **Image uploads** automatically

---

## Step 3: Add Caption

1. **Click in caption field** (below image)
2. **Type your caption:**

   ```
   Beautiful sunset from my window 🌅

   #photography #sunset #nostr
   ```

**Tips:**

- Describe what's in the image
- Add context or story
- Include relevant hashtags

---

## Step 4: Upload Multiple Images (Carousel)

**To create a carousel post:**

1. **Upload first image** (Step 2)
2. **Click "Add Another Image"**
3. **Upload second image**
4. **Repeat** for more images
5. **All images** appear in preview

**Carousel Tips:**

- Maximum images: Check your plan limits
- Order matters: First image is the cover
- Use consistent style for series
- Add caption that applies to all

---

## Step 5: Edit Image (Optional)

**Before posting, you can:**

1. **Remove image:**

   - Click "Remove" on image
   - Image removed from post

2. **Reorder images:**

   - Drag images to reorder
   - First image is the cover

3. **Replace image:**
   - Remove current image
   - Upload new image

---

## Step 6: Configure Post Settings

1. **Hashtags:**

   - Add manually or use preset
   - Include relevant tags

2. **Queue (Optional):**

   - Select queue type
   - Helps organize content

3. **Schedule (Optional):**
   - Toggle "Schedule for later"
   - Set date and time

---

## Step 7: Post or Schedule

**Option 1: Post Now**

1. **Click "Post Now"**
2. **Sign with extension**
3. **Post published** with images

**Option 2: Schedule**

1. **Toggle "Schedule for later"**
2. **Set date and time**
3. **Click "Schedule Post"**
4. **Sign with extension**
5. **Post scheduled**

---

## Image Best Practices

### File Formats

**Supported:**

- **JPEG/JPG** - Best for photos
- **PNG** - Best for graphics, transparency
- **WebP** - Modern, efficient format
- **GIF** - For animations

### File Size

**Recommendations:**

- **Optimal:** Under 2MB
- **Maximum:** 10MB (may vary by plan)
- **Large files:** May upload slowly

**Optimization Tips:**

- Compress images before upload
- Use appropriate dimensions
- Consider file format

### Image Dimensions

**Recommended:**

- **Square:** 1080x1080px (Instagram-style)
- **Landscape:** 1920x1080px (16:9)
- **Portrait:** 1080x1350px (4:5)

**Tips:**

- Consistent dimensions look better
- Square works well for most platforms
- Consider your audience

---

## Troubleshooting

### Upload Fails

**Problem:** Image won't upload

**Solutions:**

- Check file size (too large?)
- Verify file format (supported?)
- Check internet connection
- Try a different image
- Refresh page and retry

### Image Not Displaying

**Problem:** Image uploaded but not showing

**Solutions:**

- Check image preview appears
- Verify upload completed
- Try removing and re-uploading
- Check browser console for errors

### Slow Upload

**Problem:** Images upload very slowly

**Solutions:**

- Compress images before upload
- Check internet connection speed
- Use smaller file sizes
- Try during off-peak hours
