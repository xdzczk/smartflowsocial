# Using Hashtag Presets

**Estimated time:** 15 minutes  
**Difficulty:** Beginner  
**Last updated:** 2025-03-12

Learn how to create and use hashtag presets to streamline your posting workflow and maintain
consistent tagging.

---

## Prerequisites

- ✅ Account created and logged in
- ✅ Completed [Creating Your First Queue](./creating-your-first-queue.md)
- ✅ Understanding of hashtags and their importance

---

## What are Hashtag Presets?

**Hashtag presets are:**

- Reusable sets of hashtags
- Organized by topic or content type
- Automatically applied to posts
- Assigned to queues for consistency

**Benefits:**

- Save time on repetitive tagging
- Maintain consistent hashtags
- Organize by content type
- Reduce tagging errors

---

## Step 1: Navigate to Settings

1. **Click "Settings"** in navigation
2. **Go to "Content" tab**
3. **Click "Hashtags" section**
4. **Hashtag presets page** opens

---

## Step 2: Create Your First Preset

1. **Click "Create Preset"** or "New Preset" button
2. **Preset creation form** appears

---

## Step 3: Configure Preset

**Fill in preset details:**

1. **Name:**
   - Enter descriptive name
   - Example: "Bitcoin Content"
   - This appears in dropdowns

2. **Tags:**
   - Enter hashtags (space or comma separated)
   - Example: `#bitcoin #lightning #nostr #plebchain`
   - Or: `bitcoin, lightning, nostr, plebchain`
   - No need to include `#` (added automatically)

3. **Description (Optional):**
   - Add description
   - Example: "For Bitcoin-related content"
   - Helps remember preset purpose

**Example preset:**

```
Name: Bitcoin Content
Tags: bitcoin lightning nostr plebchain
Description: For Bitcoin-related content
```

---

## Step 4: Save Preset

1. **Review settings:**
   - Check name is clear
   - Verify tags are correct
   - Ensure description is helpful

2. **Click "Save"** or "Create"

3. **Preset created!**
   - Appears in preset list
   - Available for use
   - Can be edited or deleted

---

## Step 5: Assign Preset to Queue

**To automatically apply preset to queue posts:**

1. **Go to Settings → Queues**
2. **Find queue** to assign preset to
3. **Click "Edit"** on queue
4. **Select "Default Hashtag Preset"**
5. **Choose preset** from dropdown
6. **Click "Save"**

**Result:**

- Preset automatically applied to posts in this queue
- Saves time on repetitive tagging
- Maintains consistency

---

## Using Presets in Posts

### Automatic Application (Queue-Based)

**When preset is assigned to queue:**

1. **Create new post**
2. **Select queue** with preset
3. **Preset tags automatically applied**
4. **Tags appear in post**
5. **Can be edited if needed**

**Benefits:**

- No manual tagging needed
- Consistent hashtags
- Faster posting

### Manual Selection

**To use preset without queue:**

1. **Create new post**
2. **Toggle "Use Hashtag Preset"**
3. **Select preset** from dropdown
4. **Tags applied to post**
5. **Can be edited if needed**

**Use cases:**

- One-off posts
- Different content type
- Override queue preset

---

## Managing Presets

### View All Presets

1. **Go to Settings → Hashtags**
2. **See all presets:**
   - Name
   - Tags preview
   - Description
   - Assigned queues

### Edit Preset

1. **Find preset** in list
2. **Click "Edit"**
3. **Modify:**
   - Name
   - Tags
   - Description
4. **Click "Save"**

**Note:** Changes apply to all posts using this preset

### Delete Preset

1. **Find preset** in list
2. **Click "Delete"**
3. **Confirm deletion**

**Note:** Presets assigned to queues remain until queue is updated

## Preset Best Practices

### Organization

**Create presets by:**

- **Topic:** Bitcoin, Lightning, Nostr
- **Content Type:** News, Memes, Educational
- **Campaign:** Product Launch, Event Promotion
- **Frequency:** Daily, Weekly, Monthly

**Example presets:**

- "Bitcoin News" - `#bitcoin #lightning #news`
- "Memes" - `#meme #bitcoin #plebchain`
- "Educational" - `#bitcoin #lightning #tutorial`

### Tag Selection

**Tips for choosing tags:**

- Use relevant, popular tags
- Mix broad and specific tags
- Include 3-5 tags per preset
- Research trending tags
- Avoid over-tagging

**Good examples:**

- `bitcoin lightning nostr plebchain` ✅
- `bitcoin lightning nostr plebchain memes news updates daily` ❌ (too many)

### Consistency

**Maintain consistency:**

- Use same tags for similar content
- Update presets as needed
- Review presets regularly
- Remove unused presets

## Advanced: Multiple Presets

### Creating Multiple Presets

**For different content types:**

1. **Create preset for each type:**
   - Bitcoin News
   - Lightning Updates
   - Nostr Tips
   - Memes

2. **Assign to different queues:**
   - News queue → Bitcoin News preset
   - Updates queue → Lightning Updates preset

3. **Use manually when needed:**
   - Select appropriate preset
   - Override queue preset

### Preset Hierarchy

**Priority order:**

1. **Manual selection** (if enabled)
2. **Queue preset** (if assigned)
3. **No preset** (manual tagging)

## Troubleshooting

### Preset Not Applying

**Problem:** Preset not showing in post

**Solutions:**

- Check "Use Hashtag Preset" is toggled
- Verify preset is selected
- Check queue has preset assigned
- Refresh page and try again

### Tags Not Showing

**Problem:** Tags not appearing in post

**Solutions:**

- Check "Show Hashtags in Posts" setting
- Verify preset has tags
- Check post content area
- Review settings configuration

### Preset Not in Dropdown

**Problem:** Preset not available

**Solutions:**

- Verify preset is saved
- Check preset is enabled
- Refresh page
- Check for errors
