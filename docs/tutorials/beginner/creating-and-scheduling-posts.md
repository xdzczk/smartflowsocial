# Creating and Scheduling Posts

**Estimated time:** 30 minutes  
**Difficulty:** Beginner  
**Last updated:** 2026-01-03

Complete step-by-step tutorial to create posts (with or without images) and schedule them for future
publication on SmartFlowSocial.

---

## Prerequisites

Before starting, make sure you have:

- ✅ Account created and logged in
- ✅ Nostr extension installed (e.g., Alby, nos2x)
- ✅ Extension connected to your account
- ✅ Basic understanding of Nostr
- ✅ Images ready (optional, for image posts)

---

## Part 1: Creating Your First Post

### Step 1: Navigate to New Post

1. **Log in** to SmartFlowSocial
2. **Click "New Post"** in the navigation menu
   - Or go to `/dashboard/newpost`
3. **Post creation page** opens

### Step 2: Write Your Content

1. **Click in the text area**
2. **Type your post content:**

   ```
   Hello Nostr! 👋

   Just getting started with SmartFlowSocial. Excited to share content on the decentralized web!

   #nostr #bitcoin #lightning
   ```

**Tips:**

- Keep it simple for your first post
- Add hashtags for discoverability
- Use emojis to add personality

### Step 3: Add Hashtags (Optional)

**Option 1: Manual Hashtags**

- Type hashtags directly in your post
- Example: `#nostr #bitcoin #lightning`

**Option 2: Hashtag Preset**

- If you have presets configured:
  - Toggle "Use Hashtag Preset"
  - Select a preset from dropdown
  - Preset tags automatically added

---

## Part 2: Adding Images to Posts

### Step 4: Upload an Image (Optional)

**Option 1: Click to Upload**

1. **Click "Choose File"** or drag area
2. **Select image** from your computer
3. **Image uploads** automatically
4. **Preview appears** below

**Option 2: Drag and Drop**

1. **Open file explorer**
2. **Drag image** into upload area
3. **Drop image** when area highlights
4. **Image uploads** automatically

**Supported Formats:**

- **JPEG/JPG** - Best for photos
- **PNG** - Best for graphics, transparency
- **WebP** - Modern, efficient format
- **GIF** - For animations

**File Size Recommendations:**

- **Optimal:** Under 2MB
- **Maximum:** 10MB (may vary by plan)
- Compress images before upload for faster uploads

### Step 5: Add Caption (For Image Posts)

1. **Click in caption field** (below image)
2. **Type your caption:**

   ```
   Beautiful sunset from my window 🌅

   #photography #sunset #nostr
   ```

**Tips:**

- Describe what's in the image
- Add context or story
- Include relevant hashtags

### Step 6: Upload Multiple Images (Carousel)

**To create a carousel post:**

1. **Upload first image** (Step 4)
2. **Click "Add Another Image"**
3. **Upload second image**
4. **Repeat** for more images
5. **All images** appear in preview

**Carousel Tips:**

- Maximum images: Check your plan limits
- Order matters: First image is the cover
- Use consistent style for series
- Add caption that applies to all

### Step 7: Edit Images (Optional)

**Before posting, you can:**

1. **Remove image:**
   - Click "Remove" on image
   - Image removed from post

2. **Reorder images:**
   - Drag images to reorder
   - First image is the cover

3. **Replace image:**
   - Remove current image
   - Upload new image

## Part 3: Scheduling Posts

### Step 8: Choose Post Action

**You have three options:**

1. **Post Now** - Publish immediately
2. **Schedule for Later** - Set a future time
3. **Save as Draft** - Save for later editing

**For this tutorial, we'll cover both "Post Now" and "Schedule for Later".**

### Step 9: Post Now (Immediate Publishing)

1. **Review your post:**
   - Check spelling and grammar
   - Verify hashtags
   - Ensure content looks good
   - Check images (if any)

2. **Click "Post Now"**

3. **Sign with Nostr Extension:**
   - Extension popup appears
   - Review the event details
   - Click "Sign" or "Approve"

4. **Post Published!**
   - Success message appears
   - Post is published to Nostr
   - View on Nostr clients

5. **Verify Your Post:**
   - Check your Nostr client
   - Or go to Dashboard → Posted
   - Your post appears in the list

### Step 10: Schedule for Later

**Why Schedule Posts?**

- **Consistency** - Maintain regular posting schedule
- **Time Management** - Create content when convenient
- **Audience Timing** - Post when your audience is active
- **Planning** - Organize content in advance

**Enable Scheduling:**

1. **Find "Schedule for later" toggle**
   - Below the post content area
   - Or in post settings
2. **Toggle it ON**
3. **Date/time picker appears**

**Select Date and Time:**

1. **Click date field**
   - Calendar picker opens
2. **Select date:**
   - Choose future date
   - Can't select past dates
3. **Click time field**
   - Time picker opens
4. **Select time:**
   - Choose hour and minute
   - Uses your timezone

**Example:**

- Date: Tomorrow
- Time: 9:00 AM
- Timezone: America/New_York

**Using Schedule Intervals (Quick Scheduling):**

1. **Click schedule interval buttons:**
   - "2h", "4h", "6h", "12h", "24h"
2. **Time calculated automatically:**
   - From current time
   - Adds interval
3. **Adjust if needed:**
   - Fine-tune time
   - Or use as-is

**Example:**

- Current time: 10:00 AM
- Click "4h"
- Scheduled for: 2:00 PM

**Schedule the Post:**

1. **Click "Schedule Post"** button
2. **Sign with Nostr Extension:**
   - Extension popup appears
   - Review event details
   - Event signed with scheduled timestamp
   - Click "Sign" or "Approve"

3. **Post Scheduled!**
   - Success message appears
   - Post appears in "Scheduled" section
   - Will publish automatically at scheduled time

**Verify Scheduled Post:**

1. **Go to Dashboard → Scheduled**
2. **Find your post:**
   - See scheduled date/time
   - Preview post content
   - Status shows "Scheduled"
3. **Post will publish automatically:**
   - At scheduled time
   - No action needed
   - Check "Posted" section after

## Managing Scheduled Posts

### View Scheduled Posts

1. **Go to Dashboard → Scheduled**
2. **See all scheduled posts:**
   - Sorted by scheduled time
   - Shows date, time, queue
   - Preview content

### Edit Scheduled Post

1. **Find post** in Scheduled section
2. **Click "Edit"**
3. **Modify content:**
   - Change text, images, hashtags
   - Update scheduled time
4. **Save changes**
5. **Re-sign if needed**

### Reschedule Post

1. **Find post** in Scheduled section
2. **Click "Reschedule"**
3. **Select new date/time**
4. **Confirm reschedule**
5. **Re-sign if needed**

### Delete Scheduled Post

1. **Find post** in Scheduled section
2. **Click "Delete"**
3. **Confirm deletion**
4. **Post removed** from schedule

## Scheduling Tips

### Best Times to Post

**Consider:**

- **Your audience** - When are they active?
- **Time zones** - Where is your audience?
- **Content type** - News vs. evergreen
- **Platform patterns** - Nostr activity times

### Scheduling Strategies

**Consistent Schedule:**

- Same time daily
- Example: 9 AM every day
- Builds audience expectations

**Peak Times:**

- Post during high activity
- Example: Morning and evening
- Maximizes engagement

**Content Batching:**

- Schedule multiple posts
- Plan week in advance
- Maintain consistency

### Calendar View

**Visual scheduling:**

1. **Go to Dashboard → Calendar**
2. **See scheduled posts:**
   - On calendar grid
   - Visual representation
   - Easy to spot gaps
3. **Drag and drop:**
   - Move posts to different dates
   - Reschedule visually
   - Plan content visually

See [Calendar Guide](../../guides/user-guides/calendar.md) for details.

## Image Best Practices

### Image Dimensions

**Recommended:**

- **Square:** 1080x1080px (Instagram-style)
- **Landscape:** 1920x1080px (16:9)
- **Portrait:** 1080x1350px (4:5)

**Tips:**

- Consistent dimensions look better
- Square works well for most platforms
- Consider your audience

### Using Assets

**Instead of uploading each time:**

1. **Upload to Assets** first
2. **Select from Assets** when creating post
3. **Reuse images** across posts
4. **Organize with tags**

## Troubleshooting

### Extension Not Working

**Problem:** Nostr extension popup doesn't appear

**Solutions:**

- Check extension is installed and enabled
- Refresh the page
- Try a different browser
- Check extension permissions

### Post Not Appearing

**Problem:** Post created but not visible on Nostr

**Solutions:**

- Check your relays are configured
- Verify post was signed successfully
- Wait a few minutes for propagation
- Check relay status

### Signing Failed

**Problem:** Extension signing fails

**Solutions:**

- Check extension is unlocked
- Verify you have permission to sign
- Try signing again
- Check extension logs

### Upload Fails

**Problem:** Image won't upload

**Solutions:**

- Check file size (too large?)
- Verify file format (supported?)
- Check internet connection
- Try a different image
- Refresh page and retry

### Can't Select Past Date

**Problem:** Date picker won't allow past dates

**Solution:**

- This is expected behavior
- Can only schedule future posts
- Use "Post Now" for immediate posting

### Wrong Timezone

**Problem:** Scheduled time in wrong timezone

**Solution:**

- Check Settings → General → Timezone
- Update timezone if needed
- Re-schedule post

### Post Didn't Publish

**Problem:** Scheduled post didn't publish at time

**Solutions:**

- Check system is running
- Verify scheduled time passed
- Check "Posted" section
- Review error logs
