# Multi-Account Setup

**Estimated time:** 30 minutes  
**Difficulty:** Intermediate  
**Last updated:** 2026-01-02

Step-by-step guide to setting up and managing parent/child account relationships for managing multiple Nostr accounts.

---

## Prerequisites

- ✅ Parent account with Premium or Founder plan
- ✅ Child account(s) created in SmartFlowSocial
- ✅ Understanding of account relationships
- ✅ Both accounts logged in

---

## What are Parent/Child Accounts?

**Parent/Child relationships allow:**
- Managing multiple accounts from one interface
- Switching between accounts seamlessly
- Sharing features between accounts
- Organizing accounts hierarchically

**Use cases:**
- Business and personal accounts
- Multiple brand identities
- Team account management
- Account delegation

---

## Step 1: Verify Parent Account Requirements

**Before starting, ensure:**

1. **Parent account has Premium or Founder plan:**
   - Go to Settings → Subscription
   - Verify plan is Premium or Founder
   - Upgrade if needed

2. **Parent account is not a child:**
   - Check account status
   - Cannot be child and parent simultaneously

3. **Child account exists:**
   - Child must have SmartFlowSocial account
   - Account must be active
   - Not already linked to another parent

---

## Step 2: Navigate to Account Settings

1. **Log in to parent account**
2. **Go to Settings** → **Accounts tab**
3. **Account management page** opens
4. **See sections:**
   - Search for accounts
   - Confirmed children
   - Pending children

---

## Step 3: Search for Child Account

1. **In search box, enter:**
   - Account name
   - Profile display name
   - npub (public key)

2. **Search results appear:**
   - Matching accounts displayed
   - Shows profile information
   - Account status indicators

3. **Review results:**
   - Verify correct account
   - Check account status
   - Ensure not already linked

**Search tips:**
- Use npub for exact match
- Name search is fuzzy
- Results update as you type

---

## Step 4: Request Child Link

1. **Find child account** in search results
2. **Review account information:**
   - Profile name
   - npub
   - Status (available, has parent, etc.)

3. **Click "Request Link"** button
4. **Request sent:**
   - Status changes to "Requesting..."
   - Then shows "Requested"
   - Request appears in "Pending Children"

5. **Child account receives notification:**
   - Request appears in their Settings
   - Shows in "Pending Requests" section

---

## Step 5: Accept Request (Child Account)

**On child account:**

1. **Log in to child account**
2. **Go to Settings** → **Accounts**
3. **View "Pending Requests" section:**
   - See parent account request
   - Shows parent profile information
   - Request details

4. **Review parent account:**
   - Verify parent identity
   - Check parent profile
   - Ensure trust relationship

5. **Accept or reject:**
   - Click **"Accept"** to link accounts
   - Click **"Reject"** to decline
   - Request removed after decision

---

## Step 6: Verify Link Established

**On parent account:**

1. **Refresh Settings** → **Accounts**
2. **Check "Confirmed Children" section:**
   - Child account appears
   - Shows profile information
   - Link status confirmed

**On child account:**

1. **Check Settings** → **Accounts**
2. **See parent account information:**
   - Parent profile displayed
   - Link status shown
   - Can switch to parent

---

## Step 7: Switch Between Accounts

**From parent to child:**

1. **Click account switcher** in navigation
2. **See dropdown with:**
   - Current account (parent)
   - Child accounts listed
3. **Click child account**
4. **Switch confirmed:**
   - Now using child account
   - Interface updates
   - Can post from child account

**From child to parent:**

1. **Click account switcher** in navigation
2. **See dropdown with:**
   - Current account (child)
   - Parent account listed
3. **Click parent account**
4. **Switch confirmed:**
   - Now using parent account
   - Interface updates
   - Can manage children

---

## Managing Multiple Children

### Add Additional Children

**To add more child accounts:**

1. **Repeat Steps 3-6** for each child
2. **Search for new child account**
3. **Request link**
4. **Child accepts**
5. **All children appear** in "Confirmed Children"

**Best practices:**
- Organize by purpose
- Use clear naming
- Limit to necessary accounts
- Document relationships

### View All Children

1. **Go to Settings** → **Accounts**
2. **See "Confirmed Children" section:**
   - All linked children listed
   - Profile information shown
   - Can manage each

### Remove Child Account

1. **Find child** in "Confirmed Children"
2. **Click "Unlink"** or "Remove"
3. **Confirm unlinking:**
   - Relationship removed
   - Child returns to free plan
   - Can link to new parent

---

## Account Permissions

### Parent Account Permissions

**Can do:**
- Search for accounts
- Request child links
- Manage child accounts
- Switch to child accounts
- Unlink child accounts
- Cancel pending requests

**Cannot do:**
- Link to another parent (if already a child)
- Manage accounts without Premium/Founder

### Child Account Permissions

**Can do:**
- Accept/reject parent requests
- Switch to parent account
- Unlink from parent
- Use parent's features (if granted)

**Cannot do:**
- Search for accounts
- Request child links
- Manage other child accounts
- Link to multiple parents

---

## Troubleshooting

### Cannot Search for Accounts

**Problem:** Search feature not available

**Solutions:**
- Verify Premium/Founder plan
- Check account is not a child
- Refresh page
- Contact support

### Request Not Showing

**Problem:** Request sent but not appearing

**Solutions:**
- Check child account Settings
- Verify request was sent
- Refresh both accounts
- Check for errors

### Cannot Switch Accounts

**Problem:** Account switcher not working

**Solutions:**
- Verify accounts are linked
- Check relationship status
- Refresh page
- Try logging out and back in

### Link Not Establishing

**Problem:** Request accepted but link not working

**Solutions:**
- Verify both accounts active
- Check for errors
- Refresh both accounts
- Contact support if persistent

---

## Best Practices

### Account Organization

1. **Clear naming:**
   - Use descriptive account names
   - Distinguish parent from children
   - Organize by purpose

2. **Limit relationships:**
   - Only link necessary accounts
   - Keep relationships clear
   - Avoid over-complication

3. **Document relationships:**
   - Note which accounts are linked
   - Understand permissions
   - Keep track of access

### Security

1. **Trust relationships:**
   - Only link trusted accounts
   - Verify account ownership
   - Monitor linked accounts

2. **Access control:**
   - Review child account access
   - Remove unnecessary links
   - Update permissions as needed

3. **Account switching:**
   - Verify you're on correct account
   - Check account before posting
   - Use account switcher carefully
