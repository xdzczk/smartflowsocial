# Bulk Scheduling

**Estimated time:** 25 minutes  
**Difficulty:** Intermediate  
**Last updated:** 2025-03-12

Learn how to upload multiple images and schedule them automatically with consistent intervals.

---

## Prerequisites

- ✅ Account created and logged in
- ✅ Completed [Scheduling Posts](../beginner/scheduling-posts.md)
- ✅ Images ready to upload
- ✅ Basic plan or higher (bulk scheduling available on paid plans)

---

## What is Bulk Scheduling?

**Bulk scheduling allows you to:**

- Upload multiple images at once
- Automatically space posts with intervals
- Add captions to each image
- Schedule entire batches efficiently

**Use cases:**

- Product catalogs
- Photo series
- Content batching
- Automated posting schedules

---

## Step 1: Navigate to Bulk Posts

1. **Click "Bulk Posts"** in navigation
   - Or go to `/dashboard/bulkposts`
2. **Bulk posts page** opens
3. **Upload area** is ready

---

## Step 2: Upload Multiple Images

**Option 1: Drag and Drop**

1. **Open file explorer**
2. **Select multiple images:**
   - Hold Ctrl/Cmd to select multiple
   - Or select a range
3. **Drag images** into upload area
4. **Drop when area highlights**
5. **Images upload** automatically

**Option 2: Click to Select**

1. **Click "Choose Files"** or upload area
2. **File picker opens**
3. **Select multiple images:**
   - Hold Ctrl/Cmd for multiple
   - Or select range
4. **Click "Open"**
5. **Images upload** automatically

**Supported formats:**

- JPEG/JPG
- PNG
- WebP
- GIF

**File size:**

- Recommended: Under 2MB each
- Maximum: 10MB per image (may vary)

---

## Step 3: Review Uploaded Images

**After upload:**

- Images appear in grid
- Each image has:
  - Preview thumbnail
  - Caption field
  - Scheduled time
  - Queue selector

**Image order:**

- Order matters for scheduling
- First image posts first
- Can reorder if needed

---

## Step 4: Set Start Date and Time

1. **Find "Start Date/Time" field**
2. **Click date field:**
   - Calendar picker opens
   - Select start date
3. **Click time field:**
   - Time picker opens
   - Select start time
4. **First image** posts at this time

**Example:**

- Start date: Tomorrow
- Start time: 9:00 AM
- First image: Tomorrow 9:00 AM

---

## Step 5: Choose Posting Interval

**Quick intervals:**

- Click preset buttons:
  - **2h** - Every 2 hours
  - **4h** - Every 4 hours
  - **6h** - Every 6 hours
  - **12h** - Every 12 hours
  - **24h** - Every 24 hours

**Custom interval:**

- Enter custom hours
- Example: 3 hours, 8 hours

**How it works:**

- First image: Start time
- Second image: Start time + interval
- Third image: Start time + (2 × interval)
- And so on...

**Example with 4-hour interval:**

- Image 1: 9:00 AM
- Image 2: 1:00 PM (4 hours later)
- Image 3: 5:00 PM (8 hours later)
- Image 4: 9:00 PM (12 hours later)

---

## Step 6: Add Captions

**For each image:**

1. **Click caption field** below image
2. **Type caption:**

   ```
   Beautiful sunset from my window 🌅

   #photography #sunset #nostr
   ```

3. **Repeat for each image**

**Caption tips:**

- Use similar style for series
- Add variations to avoid repetition
- Include relevant hashtags
- Keep captions engaging

**Bulk caption options:**

- Add same caption to all
- Or customize individually
- Mix of both approaches

---

## Step 7: Assign Queue (Optional)

**For each image:**

1. **Click queue dropdown**
2. **Select queue:**
   - Choose from your queues
   - Or leave as "Unassigned"
3. **Queue rules apply:**
   - May adjust scheduled time
   - Applies hashtag preset (if set)

**Bulk queue assignment:**

- Select all images
- Choose queue
- Applies to all selected

---

## Step 8: Review Schedule

**Before scheduling:**

1. **Check scheduled times:**
   - Review each image's time
   - Verify intervals are correct
   - Ensure times work for audience

2. **Review captions:**
   - Check spelling
   - Verify hashtags
   - Ensure consistency

3. **Check images:**
   - Verify all uploaded correctly
   - Check image quality
   - Remove any unwanted images

---

## Step 9: Preview Posts

1. **Click "Preview X Posts"** button
   - X = number of images
2. **Preview screen shows:**
   - All scheduled posts
   - Times and dates
   - Captions and images
   - Queue assignments
3. **Review everything:**
   - Check each post
   - Verify schedule
   - Make adjustments if needed

---

## Step 10: Sign and Schedule

1. **Click "Sign and Schedule X Posts"**
   - X = number of images
2. **Nostr extension popup:**
   - Review all events
   - Check event details
   - Sign all events
3. **All posts scheduled!**
   - Success message appears
   - Posts appear in "Scheduled" section
   - Will publish automatically

## Bulk Scheduling Tips

### Organization

**Before uploading:**

- Name files in order
- Organize by topic
- Group related images
- Check file sizes

### Scheduling Strategy

**Consider:**

- **Audience activity** - When are they online?
- **Content type** - News vs. evergreen
- **Frequency** - How often to post?
- **Time zones** - Where is your audience?

**Best practices:**

- Space posts evenly
- Avoid posting too frequently
- Consider peak engagement times
- Test with small batches first

### Caption Strategy

**For series:**

- Use consistent style
- Add variations
- Include series numbering
- Maintain brand voice

**For variety:**

- Customize each caption
- Match caption to image
- Use different hashtags
- Keep it fresh

## Managing Bulk Posts

### Edit Individual Posts

1. **Go to Scheduled section**
2. **Find post** from bulk upload
3. **Click "Edit"**
4. **Modify:**
   - Caption
   - Scheduled time
   - Queue
5. **Save changes**

### Reschedule Batch

1. **Select multiple posts**
2. **Click "Reschedule"**
3. **Set new start time**
4. **Intervals recalculated**
5. **Confirm reschedule**

### Delete Posts

1. **Select posts** to delete
2. **Click "Delete"**
3. **Confirm deletion**
4. **Posts removed**

## Troubleshooting

### Upload Fails

**Problem:** Images won't upload

**Solutions:**

- Check file sizes (too large?)
- Verify file formats (supported?)
- Check internet connection
- Try smaller batch
- Refresh page and retry

### Schedule Conflicts

**Problem:** Posts scheduled at same time

**Solutions:**

- Check interval settings
- Verify start time
- Review queue rules
- Adjust schedule manually

### Signing Fails

**Problem:** Extension signing fails

**Solutions:**

- Check extension is unlocked
- Verify permissions
- Try signing in smaller batches
- Check extension logs
