## Plans Overview

### Available Plans

1. **Free** - Basic features, no cost
2. **Basic** - Enhanced features, monthly subscription
3. **Premium** - Advanced features, monthly subscription
4. **Pro** - Professional features, monthly subscription
5. **Enterprise** - Full features, custom pricing

### Plan Types

**Monthly Plans:**

- Recurring monthly payments
- Cancel anytime
- Access until period end

**Lifetime Plans:**

- One-time payment
- Lifetime access
- No recurring fees

## Plan Details

### Free Plan

**Price:** $0/month  
**Best for:** Getting started, basic posting

**Features:**

- Basic scheduling
- New post creation
- Dashboard access
- Scheduled posts view
- Posted content view
- Giveaways
- Settings access

**Limitations:**

- No drafts
- No calendar view
- No bulk scheduling
- No longform posts
- No templates
- No recyclables
- No engagement feed

### Basic Plan

**Price:** Varies (check pricing page)  
**Best for:** Regular users, content creators

**Features:**

- All Free features
- Drafts
- Calendar view
- Bulk scheduling
- Longform posts
- Templates
- Recyclables
- Engagement feed

**Limitations:**

- No multiple queues
- No reposts & quotes
- No advanced analytics
- No multi-account switching

### Premium Plan

**Price:** Varies (check pricing page)  
**Best for:** Power users, businesses

**Features:**

- All Basic features
- Multiple queues
- Reposts & quotes
- Enhanced features

**Limitations:**

- No advanced analytics
- No multi-account switching
- No Wolf filtering
- No native S3/Blossom storage

### Pro Plan

**Price:** Varies (check pricing page)  
**Best for:** Professional users, agencies

**Features:**

- All Premium features
- Advanced analytics
- Multi-account switching
- Wolf filtering & Vortex
- Native S3/Blossom storage

**Limitations:**

- No relay blast
- No visual perks

### Enterprise Plan

**Price:** Custom pricing  
**Best for:** Large organizations, custom needs

**Features:**

- All Pro features
- Relay blast
- Visual perks
- Custom features
- Priority support

## Feature Descriptions

### Basic Scheduling

**Description:** Schedule posts for future publication.

**Available in:** All plans

**Features:**

- Set date and time
- Choose queue
- Schedule single posts

### Drafts

**Description:** Save posts as drafts for later editing.

**Available in:** Basic, Premium, Pro, Enterprise

**Features:**

- Save incomplete posts
- Edit drafts later
- Multiple drafts
- Draft organization

### Calendar View

**Description:** Visual calendar of scheduled posts.

**Available in:** Basic, Premium, Pro, Enterprise

**Features:**

- Monthly calendar view
- Post scheduling visualization
- Drag-and-drop scheduling
- Date navigation

### Bulk Scheduling

**Description:** Schedule multiple posts at once.

**Available in:** Basic, Premium, Pro, Enterprise

**Features:**

- Upload multiple posts
- Batch scheduling
- Queue assignment
- Schedule intervals

### Longform Posts

**Description:** Create and schedule long-form content.

**Available in:** Basic, Premium, Pro, Enterprise

**Features:**

- Extended post length
- Rich text formatting
- Media attachments
- Thread support

### Templates

**Description:** Reusable post templates.

**Available in:** Basic, Premium, Pro, Enterprise

**Features:**

- Create templates
- Reuse templates
- Template variables
- Template organization

### Recyclables

**Description:** Recycle and repost content.

**Available in:** Basic, Premium, Pro, Enterprise

**Features:**

- Recycle old posts
- Repost content
- Schedule recycling
- Recycling intervals

### Engagement Feed

**Description:** View and manage engagement on your posts.

**Available in:** Basic, Premium, Pro, Enterprise

**Features:**

- View likes, reposts, comments
- Filter engagement
- Engagement statistics
- Interaction management

### Multiple Queues

**Description:** Create and manage multiple posting queues.

**Available in:** Premium, Pro, Enterprise

**Features:**

- Create custom queues
- Queue-specific settings
- Queue scheduling rules
- Queue organization

### Reposts & Quotes

**Description:** Repost and quote other users' content.

- Quote with commentary

- Shared features

## Upgrading Plans

### How to Upgrade

1. Go to **Settings** → **Subscription**
2. Click **"Upgrade"** or **"Change Plan"**
3. Select new plan
4. Complete payment
5. Plan activated immediately

### Plan Changes

**Upgrading:**

- Immediate access to new features
- Prorated billing (if applicable)
- No data loss

**Downgrading:**

- Access until period end
- Features removed after period
- Data preserved

**Canceling:**

- Access until period end
- No refunds (check policy)
- Can reactivate anytime

### Payment Methods

**Supported:**

- Lightning payments (NWC)
- Bitcoin payments
- Other methods (check pricing page)

**Billing:**

- Monthly recurring
- One-time (lifetime plans)
- Automatic renewal

## Plan Selection Guide

### Choose Free If:

- Just getting started
- Posting occasionally
- Basic needs only
- Testing the platform

### Choose Basic If:

- Regular posting schedule
- Need drafts and calendar
- Bulk scheduling needed
- Content creation workflow

### Choose Premium If:

- Multiple content types
- Need multiple queues
- Repost and quote content
- Business use case

### Choose Pro If:

- Professional content creation
- Multiple accounts
- Advanced analytics needed
- Agency or team use

### Choose Enterprise If:

- Large organization
- Custom requirements
- Priority support needed
- Advanced features required
